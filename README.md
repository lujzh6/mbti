# MBTI 人格探索 · 微信小程序

一款帮助用户探索 MBTI 人格类型、记录情境与查看演化趋势的微信小程序。

## 功能模块说明

### 一、用户登录
- **微信一键登录**：通过 `wx.login` 获取 code，可对接后端换取 openid（当前为本地模拟 openid）
- **首次登录**：自动创建用户档案并写入本地
- **老用户**：自动从本地加载昵称、头像、MBTI 类型、注册时间等
- **用户信息**：昵称、头像、MBTI 类型、注册时间

### 二、MBTI 测试（核心）
- **48 题精简版**：E/I、S/N、T/F、J/P 各 12 题
- **进度条**：每完成 1 题更新
- **中途保存**：支持暂停，下次进入可继续
- **答题时间**：记录每题/总耗时，便于后续分析
- **即时结果**：提交后立即计算并跳转结果页

题目设计：本土化表述、二选一强制选择、随机打乱顺序、每题配图（可选）。  
计分：每维度 12 题，得分 >6 取该维度对应倾向（如 E>6 取 E）。

### 三、测试结果报告
- 四字母类型（如 INFP）、人格名称（如 调停者）
- 四维度雷达图
- 核心特质描述（约 300 字）
- 优势与盲点（各 3 条）
- 适合职业推荐（5 个）
- 分享海报生成（可保存图片）

视觉：16 人格专属色系、卡片式布局、可下载分享图。

### 四、情境记录
- 每日打卡入口
- 场景：工作 / 学习 / 社交 / 家庭 / 独处
- 心情评分 1–10
- 行为记录（多选标签，对应能量来源、信息处理、决策方式、生活态度）
- 简短反思（可选）
- 与 MBTI 维度关联分析

### 五、演化图表
- 7 天 / 30 天维度趋势图
- 人格能量波动、场景-心情关联
- 个性化洞察提示
- 导出 PDF 报告（入口预留，付费功能）

图表：折线图（四维度变化）、热力图（场景能量）、雷达图（当前 vs 初始）。

### 六、个人中心
- 用户信息与 MBTI 类型卡片
- 测试历史、情境记录日历入口
- 设置（通知、隐私）
- 付费功能入口（预留）

## 使用与配置

1. 用微信开发者工具打开本项目，填入自己的 AppID（或使用测试号）。
2. 登录：目前 openid 为本地生成的唯一标识；正式环境需在「云开发」或自有后端用 `wx.login` 的 code 换取 openid。
3. 数据：用户档案、测试进度与结果、情境记录均存于本地 `wx.storage`；如需多端同步，需接入后端或云开发。

## 接口与存储键说明

- `user_profile`：用户档案 `{ openid, nickName, avatarUrl, mbtiType, createdAt }`
- `mbti_test_progress`：当前未完成的测试进度 `{ answers, startTime, ... }`
- `mbti_test_history`：历史测试记录数组
- `mbti_daily_records`：情境记录数组，按日期与场景存储
